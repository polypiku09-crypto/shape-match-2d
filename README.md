# Shape Match 2D

A browser puzzle game for kids: drag each 2D shape onto the shadow with the same shape and color. Works with both mouse and touch screens.

เกมจับคู่รูปทรงกับเงา 2D สำหรับเด็ก ลากและวางชิ้นส่วนให้ตรงกับเงา

**Play it:** https://polypiku.github.io/shape-match-2d/

![Shape Match 2D](screenshots/game.png)

## Features
- Drag-and-drop gameplay with mouse and touch support
- Difficulty levels: Easy (3 pieces), Normal (6), Hard (9), or Custom
- 10 rounds per game, with a timer and score
- Up to 3 stars: the faster you finish, the more stars you get
- Sound effects that can be turned on or off
- Pause and resume
- "How to play" guide
